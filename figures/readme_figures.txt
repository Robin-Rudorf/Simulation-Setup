Thesis figures
--------------
Each figure folder contains the corresponding configuration files,
analysis and plotting scripts, available analysis data, and exported
figure.
The two configuration files describe the simulation setup:

"open_runs.config" defines the parameter scan and workflow settings.
"open_boundary_generic.conf" defines the SAMoS model and integration settings.

To recreate a figure from existing data, use the analysis or plotting
script in its folder. Check its input paths and analysis settings
before running it.
To rerun the simulations, use the workflow described in the template skripts with the two configuration files supplied for the figure. See the
readme.txt in the template_skripts folder for detailed instructions.
